# caveman-discover

Find and label every LLM workflow in the repository so Caveman Cloud groups spend by workflow instead of one bucket. Use for "discover workflows" or breaking LLM spend down by workflow.

## When to Use
- Discovering LLM workflows
- Grouping spend by workflow
- Analyzing LLM usage
- Optimizing costs

## Workflow
1. **Scan** - Find all LLM-related code
2. **Label** - Identify workflow types
3. **Group** - Group by workflow
4. **Analyze** - Calculate spend per workflow
5. **Report** - Provide recommendations
