# caveman-setup

Wire a repository through the Caveman Cloud gateway so every LLM request is measured, with no behavior change. Use for "set up caveman" or adding LLM spend observability.

## When to Use
- Setting up Caveman Cloud
- Adding LLM spend observability
- Measuring LLM requests
- No behavior change required

## Setup Steps
1. **Install** - Install Caveman Cloud gateway
2. **Configure** - Configure repository settings
3. **Measure** - Start measuring LLM requests
4. **Monitor** - Monitor spend and performance
5. **Optimize** - Use insights for optimization
