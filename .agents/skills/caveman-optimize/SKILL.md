# caveman-optimize

Turn a Caveman optimization observation into an operator-chosen candidate with a paired baseline evaluation. Use when asked to inspect or evaluate a Caveman optimization report. Needs explicit approval.

## When to Use
- Inspecting optimization reports
- Evaluating optimization candidates
- Comparing baseline vs optimized
- Getting approval for changes

## Workflow
1. **Analyze** - Review optimization observation
2. **Baseline** - Establish current performance
3. **Candidate** - Generate optimization candidate
4. **Compare** - Evaluate baseline vs candidate
5. **Approve** - Get operator approval
