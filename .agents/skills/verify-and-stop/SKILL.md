# verify-and-stop

Prove existing work meets acceptance conditions without expanding scope. Use for validation-only tasks, completion checks, focused gate runs, and last-mile proof.

## When to Use
- Validation-only tasks
- Completion checks
- Focused gate runs
- Last-mile proof
- Proving work meets conditions

## Principles
1. **No Scope Expansion** - Don't add new work
2. **Focus on Conditions** - Check acceptance criteria
3. **Evidence Based** - Provide proof of completion
4. **Clear Pass/Fail** - Unambiguous results
5. **Stop When Done** - Don't continue unnecessarily

## Workflow
1. **Review** - Check acceptance conditions
2. **Test** - Verify each condition
3. **Document** - Provide evidence
4. **Report** - Clear pass/fail result
5. **Stop** - End when conditions met
