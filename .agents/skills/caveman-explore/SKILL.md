# caveman-explore

Read-only repository explorer for cold-start orientation, broad cross-file localization, or when a direct search failed. Skip it when the exact file or symbol is already named. Returns path:line citations only; its reads stay out of main context.

## When to Use
- Cold-start orientation
- Broad cross-file localization
- Direct search failed
- Repository exploration

## Output
- Path:line citations only
- Reads stay out of main context
- Compressed exploration results
- No main context pollution

## Benefits
- Preserves main context
- Fast exploration
- Compressed results
- No context pollution
