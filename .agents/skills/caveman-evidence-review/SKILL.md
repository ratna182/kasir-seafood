# caveman-evidence-review

Read-only review of Caveman Cloud evidence: cost, Cave Score, workflows, traces, latency, errors, routing, savings. Use when asked what Caveman found or where LLM spend goes.

## When to Use
- Reviewing Caveman evidence
- Analyzing costs
- Checking Cave Score
- Reviewing workflows
- Analyzing traces
- Checking latency
- Reviewing errors
- Analyzing routing
- Checking savings

## Metrics
- **Cost**: Total LLM spend
- **Cave Score**: Efficiency rating
- **Workflows**: LLM workflow breakdown
- **Traces**: Execution traces
- **Latency**: Response times
- **Errors**: Error rates
- **Routing**: Model routing decisions
- **Savings**: Token savings achieved
