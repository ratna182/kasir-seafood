# caveman

Ultra-compressed communication mode that cuts output tokens while keeping technical accuracy. Levels: lite, full, ultra and the wenyan variants. Use for /caveman, "caveman mode", "talk like caveman", "be brief" or "less tokens".

## When to Use
- Reducing output tokens
- Maintaining technical accuracy
- Quick communication
- Token optimization

## Modes
- **lite**: Minimal compression
- **full**: Standard compression
- **ultra**: Maximum compression
- **wenyan**: Classical Chinese style

## Examples
- **Normal**: "The function should validate the input parameters and return an error if any are missing"
- **Caveman**: "Func: validate params, err if missing"
