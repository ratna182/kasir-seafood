# caveman-help

Quick-reference card for caveman modes, skills and commands. Trigger: /caveman-help or "caveman help".

## When to Use
- Quick reference for caveman modes
- Understanding caveman skills
- Learning caveman commands

## Caveman Modes
- **lite**: Minimal compression
- **full**: Standard compression
- **ultra**: Maximum compression
- **wenyan**: Classical Chinese style

## Caveman Skills
- **caveman-commit**: Commit messages
- **caveman-compress**: File compression
- **caveman-review**: Code review
- **caveman-stats**: Token statistics

## Caveman Commands
- `/caveman-help`: This help card
- `/caveman-commit`: Write commit message
- `/caveman-compress`: Compress file
- `/caveman-review`: Review code
- `/caveman-stats`: Show token stats
