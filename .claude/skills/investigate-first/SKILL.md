# investigate-first

Diagnose ambiguous failures before editing. Use for unknown causes, intermittent behavior, performance regressions, or investigations needing evidence-ranked hypotheses.

## When to Use
- Unknown cause of failure
- Intermittent behavior
- Performance regressions
- Investigations needing evidence-ranked hypotheses

## Workflow
1. **Capture** - Gather all available evidence (logs, errors, symptoms)
2. **Hypothesize** - Generate ranked hypotheses based on evidence
3. **Test** - Validate each hypothesis with targeted investigation
4. **Diagnose** - Identify root cause with confidence level
5. **Recommend** - Provide evidence-based fix recommendations

## Output
- Root cause analysis with confidence level
- Evidence ranking
- Recommended fixes with risk assessment
