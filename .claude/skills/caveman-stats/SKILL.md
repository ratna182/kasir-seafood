# caveman-stats

Show real token usage and estimated savings for the current session, read from the session log. Trigger: /caveman-stats.

## When to Use
- Checking token usage
- Estimating savings
- Monitoring session costs
- Optimizing token consumption

## Output
- Total tokens used
- Estimated savings
- Token breakdown by category
- Optimization recommendations

## Token Categories
- **Input**: User messages and context
- **Output**: Agent responses
- **Tools**: Tool calls and results
- **Skills**: Skill instructions
